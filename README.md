# StoryLex Flutter 前端

正式 Flutter 项目。HTML 设计参考独立保存在 `/root/story_lex/design-reference/`，不嵌入、不加载到 Flutter 页面。

## 当前已接通

- 注册、登录、账号恢复、Token 过期处理、退出登录。
- 从后端读取词书列表，注册后选择主修词书；切换词书后重新读取首页。
- 首页真实任务、可学/到期数量、独立进度、全局累计统计、继续阅读信息。
- 修改每日新学/复习目标（1～200），成功后重新读取服务端统计。
- 个人中心基础信息，桌面侧栏与手机底栏。
- 文章库：我的书库/系统推荐分区、标题搜索、导入/AI/收藏分类、独立分页、文章收藏。
- 阅读：正文内嵌单词查词、显示/隐藏释义、词表、单词收藏和标记已掌握。
- 阅读位置自动保存、返回前保存；文章库从头阅读，首页“继续阅读”恢复位置；并发版本冲突提示重新载入。
- 手动完成阅读；阅读到末尾和完成练习均不会自动完读。
- 阅读课后练习：后端出题、提交选项判题、服务端成绩和错词排程结果。

- 新学单词：服务端出题与判题、答错后重练、组内标熟、收藏、小组结算和下一组。
- 正式复习：到期数量与今日目标、后端出题和判题、每词答一次、查看答案与复习小结。
- 未完成学习刷新恢复；答题与结算失败可使用原请求安全重试。

独立单词收藏页及 AI/TXT 导入草稿流程尚待接入。文章库本批不显示未接通的导入按钮。

新学按后端题组实际数量结算，最后一组可不足 10 词；组内点“熟”直接通过。新学单词的次日排程由后端处理。新学接口未提供发音音频，本批不显示播放按钮。

阅读页的单词收藏不会加入正式复习队列；阅读练习的错词排程由后端处理。查词接口没有提供例句或音频，本批不展示虚构内容。
文章库每次打开从头阅读；首页“继续阅读”使用保存的正文字符偏移，恢复到对应段落附近；跨设备字号与换行不同，位置可能略有差异。网页版直接关闭标签页前的最后一次未发送位置可能来不及保存，建议使用页面内返回或“保存位置”。

## 启动网页版

先让 Python 后端运行在 5000 端口，再在独立终端执行：

```sh
cd /root/story_lex/frontend
source /root/.bashrc
flutter --no-version-check run -d web-server --web-hostname=0.0.0.0 --web-port=8088 --dart-define=API_BASE_URL=http://192.168.30.97:5000
```

浏览器打开 http://192.168.30.97:8088/ 。终端保持运行，停止用 Ctrl+C。服务器不需要安装桌面 Chrome，直接用你自己电脑的浏览器访问。

如果找不到 Flutter，将命令开头的 flutter 替换为 `/root/develop/flutter-sdk/bin/flutter`。

## 配置与会话

- 后端地址用编译参数 `API_BASE_URL`，默认为 `http://192.168.30.97:5000`，不含尾部 `/api`。修改后需要重新启动/构建应用。
- 前端不放数据库密码或模型 API Key。
- 网页登录凭证使用当前标签页的 sessionStorage，刷新可恢复，关闭标签页后需重新登录；禁用浏览器存储时退回本次页面内登录。
- Android/iOS 使用系统安全存储，代码与网页存储通过条件导入区分。
- 退出登录清除客户端凭证，并清除学习恢复记录，当前后端未提供服务端 Token 撤销接口。
- 请求检查 HTTP 状态和响应体 code，401 清理本地登录状态，一般写请求失败不自动重发；新学答题保留原 request_id，结算保留 group_id，明确重试时复用原请求。
- 服务器需允许 API 跨域；现有 Flask 配置已允许 `/api/*`。网页 HTTPS 部署时 API 也应使用 HTTPS。

## 项目结构

```text
lib/
  core/        HTTP 客户端与分平台会话存储
  data/        后端模型
  state/       登录、词书、首页与阅读位置状态
  ui/          主题、公共组件、页面
  app.dart     登录状态入口
  main.dart    启动入口
assets/        本地完整中文字体、许可证和插画
web/           Flutter 网页启动文件（框架必需，不是旧 HTML 样稿）
test/          HTTP、会话与界面测试
```

## 验证与构建

```sh
flutter --no-version-check analyze
flutter --no-version-check test
flutter --no-version-check build web --no-web-resources-cdn --dart-define=API_BASE_URL=http://192.168.30.97:5000
```

测试只用模拟 API，不会注册真实账号、写入数据库或修改学习进度。实际联调请使用自己的测试账号。构建输出为 `build/web/`，需要通过 HTTP 服务访问。

本批以 Web 为验收目标。Android/iOS 工程和安全存储基础已保留，未打包验证；Android SDK、macOS/Xcode、签名与移动端 HTTP/HTTPS 配置需在对应环境后续完成。Android 明文 HTTP 仅在 debug 配置中允许，release 应使用 HTTPS。

字体：Noto Sans SC、Noto Sans（音标）、ZCOOL KuaiLe，许可证位于 `assets/fonts/`。插画沿用已确认的手帐样稿素材。
